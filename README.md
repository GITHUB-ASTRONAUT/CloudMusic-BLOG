# 紫听歌嘞 · PURPLE MUSIC

自托管的网易云音乐 Web 播放器。**零 npm 依赖、零构建步骤**：前端是原生 ES Module 单页应用，后端是一个 200 多行的 Node 静态服务 + 反向代理。克隆下来 `node server.mjs` 就能跑。

音乐数据来自本地运行的第三方接口项目 [NeteaseCloudMusicApi-enhanced](https://neteasecloudmusicapienhanced.js.org/)，本项目不存储、不分发任何音频。

## 特性

**播放**
- 队列管理：播放全部 / 下一首播放 / 加入队列 / 队列页拖动之外的增删清空
- 四档播放模式：列表循环 → 单曲循环 → 随机 → **心动模式**（网易云智能播放，需登录且当前歌已在「我喜欢的音乐」里）
- 五档音质切换，并回显**实际到手**的档位与码率：请求无损但账号权益不够时显示「无损 → 实际 极高 320k」，试听曲标注「试听 20s」
- 歌词逐句同步滚动，可调字号、字体、对齐、未唱模糊、翻译开关
- 沉浸模式：一键隐藏播放栏与侧栏文字；封面黑胶随播放状态转停
- 氛围光：Canvas 采样专辑封面主色调，动态改写 CSS 变量，全站配色跟着当前歌走
- 接入 MediaSession，支持系统媒体键与锁屏封面

**评论侦探**
- 解决网易云的一个真实痛点：**没有「按用户筛选某首歌评论」的接口**，而很多人把自己的历史评论设成了仅自己可见之外的隐藏状态，翻页根本翻不到
- 双通道扫描：先秒扫「最热池」（所有被点过赞的评论），再把歌曲的评论时间线切成 6 段，6 路并发各自倒查
- 突破点在于上游只有 `before=<毫秒时间戳>` 能任意 seek（纯 offset 深翻会归零），因此可以对时间轴分片并行
- 可选时间范围与本轮扫描预算，命中结果实时冒出，约每秒 800~1000 条

**其它**
- 发现 / 排行榜 / 每日推荐 / 我的歌单 / 搜索（歌曲与用户）/ 歌单 / 专辑 / 单曲 / 用户主页 / 播放队列
- 搜索联想下拉、聚焦展开动效
- 三种登录方式：二维码、手机号 + 密码、手机号 + 验证码
- 喜欢 / 取消喜欢、评论点赞、回复、删除（需登录）

## 快速开始

**前置**：Node.js 18+（需要内置 `fetch`），以及本机 3000 端口上跑着 api-enhanced：

```bash
cd path/to/api-enhanced
node app.js
```

**启动本项目**：

```bash
node server.mjs
# ▶ http://127.0.0.1:8080
#   api proxy /api/*  ->  http://127.0.0.1:3000
```

Windows 下可以直接双击 `start.cmd`（含代理链路自检与端口占用处理），`stop.cmd` 停止服务。公网映射见 [DEPLOY.md](DEPLOY.md)。

**可配环境变量**

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 静态服务端口，只监听 `127.0.0.1` |
| `API_BASE` | `http://127.0.0.1:3000` | 上游接口地址 |
| `REAL_IP` | 空（不注入） | 设置后转发时注入 `realIP`；海外网络下上游部分接口会拒绝返回数据，此时填一个国内 IP |

## 架构要点

**凭证隔离**。浏览器永远拿不到网易云的 Cookie。前端只认一个 `HttpOnly` 的 `wyybok_sid`，`server.mjs` 用它索引一份**只存在于内存**的 cookie jar；上游返回体里夹带的 `cookie` 字段会被摘走再转发，`/logout` 直接清空对应 jar。进程重启即登出，磁盘上不留任何凭证。

**同源图片代理**。`/api/__img` 只放行 `music.126.net` / `music.127.net`，把封面转成同源资源——否则 Canvas 无法读取像素，取色功能会被跨域策略拦住。

**零依赖 SPA**。hash 路由表 + 页面函数 + 发布订阅状态层，全部手写；模板走一个自动转义的标签模板函数 `html`，插值默认转义，需要原样输出时显式调用 `raw()`，从源头挡掉 XSS。

**上游三个坑**（评论侦探的设计前提）：`/comment/new` 的游标深翻会失效；`/comment/music` 的纯 offset 超过约 1000 条后归零；只有 `before=<ms>` 能任意跳转——这才是并行分片可行的原因。

## 已知限制

- 播放队列不做持久化，刷新即重置
- 登录态存在服务端内存，重启服务需要重新登录
- 心动模式依赖登录，且种子歌曲必须已在「我喜欢的音乐」中
- VIP 曲目未开通会员时只能拿到 20~30 秒试听片段，无损与 Hi-Res 会被上游降级
- 上游 api-enhanced 监听 `0.0.0.0` 且无鉴权，同一局域网可直连

## 安全须知

本项目默认只绑 `127.0.0.1`。如果你用 Cloudflare Tunnel 之类的方式映射到公网，请务必加一层访问控制（例如 Cloudflare Access 邮箱 OTP）：**入口无鉴权 + 服务端持有你的网易云会话 = 任何知道地址的人都能以你的身份操作**。详见 [DEPLOY.md](DEPLOY.md)。
